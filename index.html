Engineering principles

Built to be trusted.

Security first

TLS transport, per-device credentials, hashed secrets and role-based access. No passwords or database keys in front-end code.

Safe by default

Mains-connected designs follow isolation, protection and fail-safe practice, with manual override kept wherever it matters.

Offline tolerant

Devices keep working when the network drops and sync cleanly when it returns.

FAQ

Quick answers.

Can you build fully custom hardware?

Yes. We handle schematic and PCB design, firmware, enclosure design and the cloud dashboard, so the device and the software are designed together.

Will my existing wall switches keep working?

With NX-SW4, yes. It is a retrofit controller: manual switching always works, even when Wi-Fi is down.

How long does a prototype take?

It depends on scope. Use the project planner for an indicative outline; we confirm after a short discovery call.

Do you run workshops for colleges and schools?
